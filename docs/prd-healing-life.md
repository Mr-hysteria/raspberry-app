# PRD v3 - Healing Life 每日阅读屏

## 1. 文档信息

- 产品名称：愈见·生活（Healing Life）
- 文档版本：`v3`
- 状态：`Draft`
- 记录日期：`2026-08-30`
- 适用项目：`raspberry-clock`

## 2. 一句话产品定义

愈见·生活是一款以时间为锚点、以每日古诗文片段营造阅读氛围、以极轻触摸仪式帮助开始阅读的桌面摆件。

## 3. 产品定位

它不是任务管理器，也不是打卡工具，而是一块放在书桌上的低唤醒阅读屏：

- 用时间提供稳定秩序感
- 用简短、可追溯来源的中文诗句承接阅读氛围
- 用低对比、确定性的背景维持安静感
- 用夜间自动息屏减少持续打扰

## 4. 当前约束

### 硬件与运行环境

- 设备：`Raspberry Pi Zero 2 W`
- 内存：`512MB`
- 屏幕：`800×480`
- 形态：触摸屏
- 技术方案：`Rust + Slint`
- 渲染路径：软件渲染优先
- 运行环境：`X11`

### 产品约束

- 允许轻触交互
- 不允许手动录入数据
- 不做统计、打卡、提醒、积分、连续计数
- 联网时更新当日阅读内容，断网时保留核心时钟和缓存内容
- 优先保证常驻稳定和低干扰，而不是追求复杂动效或高度可配置

## 5. 产品目标

### 核心目标

- 让设备从单纯报时工具升级为能陪伴开始阅读的桌面摆件
- 在小屏上维持清晰、留白和稳定，而不是塞入更多信息模块
- 用足够克制的交互降低开始阅读的心理门槛

### 设计关键词

- 低唤醒
- 平静
- 克制
- 留白
- 陪伴
- 书桌感

## 6. 非目标

以下内容不属于当前版本范围：

- 阅读计时器、番茄钟、进度统计、排行榜
- 手动录入阅读页数或生活数据
- 用户账户、跨设备同步和云端历史记录
- 高负载动画、远程图片管线、复杂视觉特效
- 每日内容的深度内容审核承诺

## 7. 当前范围

当前版本包含以下模块：

1. 时间
2. 日期与星期
3. 每日古诗文片段与来源行
4. 白天轻触开始仪式
5. 双槽 JSON 缓存与离线回退
6. 程序化背景与昼夜色板
7. 夜间定时息屏和触摸临时唤醒

## 8. 功能设计

### 8.1 时间

- 作为主视觉核心
- 使用大字号展示当前时间
- 秒数存在但弱化，不与小时和分钟竞争
- 默认每秒刷新一次

### 8.2 日期与星期

- 展示完整日期与星期
- 作为辅助信息，不抢主视觉
- 与时间形成上半屏的稳定秩序感

### 8.3 每日阅读内容

- 数据来源为今日诗词 v1 JSON 接口
- 仅使用五条固定分类路由，按本地自然日稳定选择其中一条
- 屏幕展示一条中文诗句和一行来源信息
- 来源信息格式为“作者《作品》 · 分类”
- 响应必须同时具有非空的 `content`、`origin`、`author` 和 `category`
- 内容超过 `40` 个 Unicode 字符时拒绝展示
- 内容命中负向词过滤时拒绝展示，并保留当前内容
- 过滤目的仅为保护书桌氛围，不宣称完整内容安全审查

### 8.4 本地缓存与离线回退

- 缓存目录保持 `~/.cache/raspberry-clock`
- 当前缓存文件为 `daily-reading.json`
- 只保留 `current` 和 `previous` 两条成功内容
- 启动时优先显示 `current`，其次 `previous`
- 两个槽位都不可用时回退到内置诗句
- 成功写入新 JSON 后，再清理历史版本已知旧缓存文件

### 8.5 开始仪式

- `07:00–23:30` 之间，首次轻触进入开始状态，再次轻触返回普通状态
- 开始状态不计时、不计数、不落盘
- 开始状态只改变底部提示文案和阅读文字对比度
- 进入夜间息屏窗口时自动清除开始状态

### 8.6 夜间息屏

- 每天 `23:30–07:00` 默认关闭显示器
- 夜间触摸后临时亮屏 `60` 秒
- 临时亮屏期间再次触摸会重新计时
- 夜间触摸不切换开始仪式
- `07:00` 后恢复正常常亮

## 9. 视觉设计方向

### 总体风格

- 低饱和、低对比、安静、克制
- 避免效率工具感和控制面板感
- 背景由程序化色板和抽象形状构成，不依赖外部素材

### 昼夜色系

白昼模式：

- 温和的灰米、雾绿、浅棕、冷暖中性色
- 让文字仍然是最强阅读焦点

夜晚模式：

- 更暗的墨灰底色
- 低亮暖色或灰绿文字
- 收敛亮度，避免夜间刺眼

### 动效原则

- 不引入持续动画作为核心体验
- 优先保证 `800×480`、软件渲染和低内存设备稳定性
- 所有视觉变化都应是低频、确定性、可预期的

## 10. 布局原则

基于 `800×480` 屏幕，布局遵循以下原则：

- 上半屏强调时间与日期秩序
- 中下区域呈现“今日一页”与来源
- 底部提示只承担轻触引导，不形成任务压力
- 控制信息密度，保持留白和层次

## 11. 数据与状态来源

### 系统时间

- 用于时间、日期、星期和夜间窗口计算

### 今日诗词

- 当缓存日期落后于本地日期时发起请求
- 当天成功后不再重复请求
- 当天失败后至少每 `15` 分钟重试一次
- 使用本地 JSON 缓存支持断网回退

### 本地运行时状态

- 开始仪式状态只保存在内存中
- 夜间临时亮屏截止时间只保存在内存中

## 12. 性能与实现要求

### 技术要求

- 继续采用 `Rust + Slint`
- 优先兼容当前软件渲染方案
- 不引入明显增加运行负担的重型依赖
- 网络请求必须在后台线程执行，不能阻塞 Slint 事件循环

### 性能要求

- 常驻运行稳定
- 时间显示刷新准确
- 每天成功请求最多一次
- 失败重试间隔不少于 `15` 分钟
- 在 `512MB` 设备上保持低资源占用

### 降级策略

- 无法联网时继续显示缓存或内置诗句
- 缓存损坏时回退到内置诗句，而不是阻塞界面
- 字体不可用时优先保证中文可读性

## 13. 验收标准

### 功能验收

- 主界面可稳定显示时间、日期、星期
- 主界面可展示每日诗句及来源信息
- 白天轻触可切换开始提示；夜间轻触仅负责临时亮屏
- 断网时可使用缓存或内置默认诗句
- `23:30–07:00` 可自动息屏
- 夜间触摸后可亮屏 `60` 秒并重新计时

### 内容验收

- 今日内容只能来自五条固定分类路由之一
- 缺失必填字段的响应不会进入展示
- 超过 `40` 字或命中负向词过滤的内容不会替换当前内容
- 来源行能展示作者、作品和分类末段

### 视觉验收

- 在 `800×480` 屏幕上信息不拥挤、不裁切
- 时间始终是最强视觉中心
- 普通、开始、夜间三种状态布局一致，只改变必要提示和对比度
- 背景稳定、克制，不依赖外部图片素材

### 稳定性验收

- 应用长时间运行不影响核心显示
- 网络不可用时核心时钟、阅读内容和夜间逻辑仍可工作
- 背景和内容更新不会阻塞主界面刷新
