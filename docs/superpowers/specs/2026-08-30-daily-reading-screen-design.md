# 每日阅读屏产品与技术设计

## 目标

将 CPA 倒计时信息海报改造成放在书桌上的低唤醒阅读摆件。页面每天提供一段有明确作者和作品名的中文古诗文，在保留时间、日期和夜间息屏能力的同时，用稳定而安静的视觉线索降低“开始阅读”的心理门槛。

## 心理设计原则

- 使用低唤醒积极情绪，不用强烈口号、任务数字、连续打卡或倒计时制造压力。
- 时间仍是稳定的视觉锚点，但不再显示年度剩余和 CPA 倒计时。
- 每日内容承担“阅读氛围”和轻微好奇心，而不是充当需要严谨引用的百科事实。
- 白天轻触屏幕形成一个极短的开始仪式；不启动计时器、不记录次数、不制造失败感。
- 背景保持低对比度和确定性，避免每天随机照片造成视觉噪音。

## 屏幕内容

屏幕固定为 `800×480`，包含四层信息：

1. `HH:MM` 大时钟和弱化的秒数。
2. 完整日期和星期。
3. “今日一页”中文诗句，以及“朝代 · 作者《作品名》”来源行。
4. 底部轻提示。默认文案为“轻触一下，先读一页”；白天轻触后变为“已经开始了，先读一页就好”。

移除以下旧内容：

- CPA 考试倒计时及考试日期卡片。
- 年度剩余百分比及进度条。
- 金山词霸英文、中文双语句子。
- 在线背景图片和全屏照片遮罩。

## 一触开始交互

- 07:00–23:30 之间，第一次轻触进入开始状态，再次轻触返回普通状态。
- 开始状态不计时、不计数、不落盘；时钟保持可见，阅读片段降低对比度，底部提示切换为“已经开始了，先读一页就好”。
- 23:30–07:00 之间，触摸仍只负责把息屏临时唤醒 60 秒，不切换开始状态。
- 进入夜间息屏窗口时自动清除开始状态，第二天从普通状态开始。

## 在线内容源

使用今日诗词 v1 JSON 接口，候选分类固定为：

- `https://v1.jinrishici.com/rensheng/dushu.json`
- `https://v1.jinrishici.com/rensheng/zheli.json`
- `https://v1.jinrishici.com/shanshui.json`
- `https://v1.jinrishici.com/shenghuo/tianyuan.json`
- `https://v1.jinrishici.com/rensheng/lizhi.json`

本地日期通过稳定散列选择当天分类。每次刷新只请求一个接口，成功后当天不再请求；失败后至少 15 分钟再试，避免触发上游限流。

响应必须同时具有非空的 `content`、`origin`、`author` 和 `category`。诗句超过 40 个 Unicode 字符，或包含明显低落、死亡、战争、病痛与悔恨词语时拒绝展示并保留当前内容。过滤只作为书桌氛围保护，不宣称完整的内容安全审查。

真机无代理验证（2026-08-30）：今日诗词读书接口返回 `HTTP 200`，连接约 `0.05s`、完整响应约 `0.33s`，响应约 `168B`。

## 缓存与离线回退

缓存目录保持 `~/.cache/raspberry-clock`，新缓存文件为 `daily-reading.json`。

缓存使用两个槽位：

- `current`：最近一次成功获取、用于某个本地日期的内容。
- `previous`：`current` 被新日期内容替换前的上一条成功内容。

启动时优先显示 `current`，其次 `previous`，都不存在或损坏时显示内置公版诗句：

> 读书不觉已春深，一寸光阴一寸金。  
> 唐 · 王贞白《白鹿洞二首·其一》

缓存采用同目录临时文件加原子重命名。只有新 JSON 成功写入后，才清理旧版 `daily-quote.json` 和已知命名的 `daily-quote` 图片文件；不得删除缓存目录中的其他文件。运行期和磁盘上都不保存历史列表。

## 程序化背景

- 背景完全由 Slint 的颜色、渐变和低透明度圆角形状绘制，不请求、不解码、不缓存远程图片。
- 本地日期稳定选择一套低饱和日间色板；同一天重启后色板不变化。
- 夜间色板使用更暗的墨灰底色和低亮暖色文字。
- 背景不使用动画，优先保证 Raspberry Pi Zero 2 W 的软件渲染稳定性。
- UI 字体统一使用真机已经安装的 `WenQuanYi Zen Hei`，避免原设计指定但真机缺失的 `Noto Serif CJK SC` 静默回退。

## AIC 取舍

Art Institute of Chicago 元数据接口在树莓派无代理环境中可返回 `HTTP 200`，但 `www.artic.edu/iiif/2` 图片请求被 Cloudflare managed challenge 拦截并返回 `HTTP 403`。因此 AIC 不进入运行时、缓存或降级链路，本版本只使用本地程序化背景。

## 保留的既有能力

- Rust + Slint 原生应用和软件渲染路径。
- 每秒刷新时间。
- 后台线程执行网络请求，绝不阻塞 Slint 事件循环。
- 23:30–07:00 通过 X11 DPMS 自动息屏。
- 夜间触摸唤醒 60 秒，再次触摸延长 60 秒。
- LightDM/LXDE 自启动和异常退出守护脚本。

## 性能约束

- 不新增运行时图片解码与图片缓存。
- 不新增数据库、浏览器、异步运行时或常驻网络连接。
- 每天成功请求最多一次；失败重试间隔不少于 15 分钟。
- 目标设备为 Raspberry Pi Zero 2 W、512MB 内存、Debian 13 64-bit、800×480 X11 屏幕。

## 验收标准

### 自动验证

- 今日诗词 JSON 的正确解析、必填字段校验、长度限制和负向词过滤均有单元测试。
- 日期到分类的选择稳定且只落在白名单接口。
- 双槽缓存的首次写入、跨日轮换、同日替换、损坏回退和原子写入均有单元测试。
- 旧版缓存清理只触及已知文件，保留无关文件。
- 白天触摸切换开始状态，夜间触摸不切换；进入夜间时清除状态。
- 程序化色板对同一日期确定，日间和夜间具有足够的明暗差异。
- Rust 全量测试、Shell 测试、格式检查、release 构建和 `aarch64-unknown-linux-gnu` 交叉编译全部通过。

### 视觉验证

- 生成普通、开始、夜间三张 `800×480` 实际 Slint 渲染截图。
- 普通截图中时间、日期、诗句、来源和轻触提示均完整可见，无文字裁切或元素越界。
- 开始截图中提示切换，诗句弱化但仍可辨识。
- 夜间截图对比度收敛且布局不跳动。

### 树莓派真机验证

- 部署 release 二进制后，设备从无代理网络成功获取今日诗词并写入新缓存。
- 真机截图为 `800×480`，不再出现 CPA、年度剩余或远程照片。
- 白天触摸可切换开始提示。
- 23:30–07:00 息屏与 60 秒触摸唤醒逻辑通过受控逻辑测试；实际 DPMS 命令和应用进程在 X11 会话中正常。
- 记录部署后的 RSS、缓存大小和进程存活状态，并与改版前约 `23MB RSS`、`2.67MB` 图片缓存基线比较。
